# @keytuno/ui-react v1.0.0

Release date: 2026-07-01

## Summary

First stable `1.0.0` release of `@keytuno/ui-react` for Keytuno applications.

## Highlights

1. Stable major release baseline with standalone package exports (`dist/index.js`, `dist/index.d.ts`).
2. React component system, theme tokens/contracts, adapters, and themes are release-ready.
3. Storybook documentation and build pipeline are included for component discovery and review.
4. Contributor and operations docs are aligned for team-ready handover.

## Post-Release Maintenance Update (2026-07-29)

1. Refreshed light/dark semantic palettes with newer neutral surfaces and updated action hues.
2. Added semantic tokens and CSS variables for interactive surfaces and danger/border emphasis:
	- `backgroundHover` / `--ktn-bg-hover`
	- `backgroundSelected` / `--ktn-bg-selected`
	- `borderStrong` / `--ktn-border-strong`
	- `actionDangerBackground` / `--ktn-action-danger-bg`
	- `actionDangerForeground` / `--ktn-action-danger-fg`
3. Added variant soft-surface tokens for light backgrounds:
	- `actionPrimarySoftBackground` / `--ktn-action-primary-soft-bg` (`#dbeafe`)
	- `actionSuccessSoftBackground` / `--ktn-action-success-soft-bg` (`#dcfce7`)
	- `actionWarningSoftBackground` / `--ktn-action-warning-soft-bg` (`#fef3c7`)
	- `actionAccentSoftBackground` / `--ktn-action-accent-soft-bg` (`#fce7f3`)
	- `actionDangerSoftBackground` / `--ktn-action-danger-soft-bg` (`#fee2e2`)
4. Updated Badge and BadgeSelect visuals to be borderless.
5. Added theme-aware hover/selected treatment for BadgeSelect options in both light and dark themes.
6. Applied soft token surfaces across Badge, Toast, and Alert variants for brighter light-theme feedback.
7. Added dedicated button semantic tokens for refreshed tones across themes (light examples: primary `#2563eb`, destructive `#ef4444`, default/secondary background `#edf2f7`).
8. Updated Button hover behavior with enterprise-style emphasis: each variant darkens background on hover and also updates border/text colors for clearer affordance.

## Post-Release Maintenance Update (2026-07-31)

1. Fixed `AdvanceFilter` so newly added filter rows can be removed immediately, including when only one filter row exists.
2. Kept per-rule row removal behavior consistent across filters and sorts with clear remove labels.
3. Added regression tests covering add/remove flows for filter and sort rows in `AdvanceFilter`.

## Toolchain and Compatibility Baseline

2. pnpm 9+
3. React peer dependencies: `react ^18.0.0`, `react-dom ^18.0.0`
