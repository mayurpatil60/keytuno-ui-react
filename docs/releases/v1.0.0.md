# @keytuno/ui-react v1.0.0

Release date: 2026-07-01

## Summary

First stable `1.0.0` release of `@keytuno/ui-react` for Keytuno applications.

## Highlights

1. Stable major release baseline with standalone package exports (`dist/index.js`, `dist/index.d.ts`).
2. React component system, theme tokens/contracts, adapters, and themes are release-ready.
3. Storybook documentation and build pipeline are included for component discovery and review.
4. Contributor and operations docs are aligned for team-ready handover.

## Toolchain and Compatibility Baseline

1. Node.js 18+
2. pnpm 9+
3. React peer dependencies: `react ^18.0.0`, `react-dom ^18.0.0`

## Quality Gate

Validated on release branch `main` with:

1. `pnpm install --frozen-lockfile`
2. `pnpm lint` (warnings only, no blocking errors)
3. `pnpm typecheck`
4. `pnpm test`
5. `pnpm build`
6. `pnpm build-storybook`
7. `pnpm size`
8. `pnpm audit --prod --audit-level high`

Quality snapshot (2026-07-01 verification):

1. No TypeScript or build errors.
2. Unit test baseline passes.
3. Bundle budgets pass size-limit checks.
4. No known high-severity production dependency vulnerabilities.
5. Lint remains non-blocking with warning-only follow-up work.

## Install

```bash
pnpm add git+https://github.com/mayurpatil60/keytuno-ui-react.git#v1.0.0
```

## Known Compatibility Note

React 19 consumer apps may need `--legacy-peer-deps` until peer ranges are widened in a later release.
