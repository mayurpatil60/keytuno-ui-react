# @keytuno/ui-react v0.1.0

Release date: 2026-06-30

## Summary

Initial tagged release of `@keytuno/ui-react` as a standalone React UI library for Keytuno applications.

## Highlights

1. Standalone package structure with public exports through `dist/index.js` and `dist/index.d.ts`.
2. React component surface available for app integration (buttons, inputs, overlays, data display, feedback, and utility components).
3. Theme system modules included (tokens, contracts, adapters, and theme definitions).
4. Storybook integration included for interactive component documentation.
5. Team handover docs in place: contribution guide, operations, and compatibility guidance.

## Toolchain and Compatibility Baseline

1. Node.js 18+
2. pnpm 9+
3. React peer dependencies: `react ^18.0.0`, `react-dom ^18.0.0`

## Quality Gate

Validated on release branch `main` with:

1. `pnpm install --frozen-lockfile`
2. `pnpm lint` (warnings only, no blocking errors)
3. `pnpm typecheck`
4. `pnpm test`
5. `pnpm build`
6. `pnpm build-storybook`

## Install

```bash
pnpm add git+https://github.com/mayurpatil60/keytuno-ui-react.git#v0.1.0
```

## Known Compatibility Note

React 19 consumer apps may need `--legacy-peer-deps` until peer ranges are widened in a later release.
