# @keytuno/ui-react v2.0.0

Release date: 2026-10-31

## Summary

Major release rolling up everything that landed on `main` after `v1.0.0`. It contains one breaking change (removal of the table exporters addon), so it is a major version per the SemVer policy in `docs/OPERATIONS.md`.

## Breaking Changes

1. Removed the `@keytuno/ui-react/addons/table-exporters` subpath export (`src/addons/table-exporters.ts`).
2. Removed the optional `jspdf`, `jspdf-autotable`, and `xlsx` peer dependencies that `v1.0.0` shipped.
3. `Navbar` no longer has a `soft` variant; use `light` or `brand-light`.

Migration: consumers that imported `@keytuno/ui-react/addons/table-exporters` must own their export logic. `Table` now covers filter/sort/search/pagination and table-card switching only.

## New Components

1. `AdaptiveCard`
2. `AdvanceFilter` (filter/sort rule builder; added rows can be removed immediately, including a single remaining row)
3. `BadgeSelect`
4. `CardGroup`
5. `DataToolbar`
6. `StepwiseForm`

## Changes

1. Refreshed light/dark semantic palettes and added semantic tokens: `backgroundHover`, `backgroundSelected`, `borderStrong`, `actionDangerBackground`, `actionDangerForeground`.
2. Added soft variant surface tokens (`--ktn-action-{primary,success,warning,accent,danger}-soft-bg`) and dedicated button tone tokens (`--ktn-button-*`).
3. Badge and BadgeSelect are borderless; Badge, Toast, and Alert use soft surfaces in light theme.
4. Button hover darkens background and updates border/text colors per variant.
5. Button-like variants `success`, `warning`, `accent`, and `destructive` are available across Badge, BadgeSelect, Button, ButtonGroup, Alert, Dialog, and InputGroup; Toast adds `accent`.
6. Hardened `AdaptiveCard` link/media fields, `FilePreview`, and `FileUpload` against unsafe URL schemes; `FileUpload` enforces `accept` on drag-and-drop.
7. Expanded Storybook coverage for the new and reworked components (Sidebar, Table, Dialog, Sheet, FileUpload, and others).
